# 📝 React Todo List App

This is a simple and interactive Todo List web application built with **React JS** using **Vite** as the build tool. It allows users to add, update, delete, and clear tasks efficiently with a responsive UI.

## 🚀 Features

- ✅ Add new tasks
- 📝 Update existing tasks
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks
- 💾 Unique IDs for tasks using `uuid`
- 🎨 Basic styling with responsive design

## 📦 Tech Stack

- **React JS**
- **Vite**
- **UUID** (for unique task IDs)
- **CSS** (custom component styling)
- **Font Awesome** (for icons)
